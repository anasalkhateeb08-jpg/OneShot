# قوائم التحقق

## المرحلة 0: الهيكل

ينفّذها المالك على جهازه، ويضع علامة عند نجاح كل بند.

- [ ] فُكّت الحزمة، وصار المجلد `F:\OneShot` يحتوي `package.json` و`client` و`server` و`shared` و`docs` و`tools`.
- [ ] الأمر `.\tools\run.ps1 npm install` انتهى برمز خروج 0.
- [ ] الأمر `.\tools\run.ps1 npm run format` انتهى برمز خروج 0.
- [ ] الأمر `.\tools\run.ps1 npm run check` انتهى برمز خروج 0 (فحص الأنواع، والتدقيق، والتنسيق، والاختبارات).
- [ ] الأمر `.\tools\run.ps1 npm run build` انتهى برمز خروج 0.
- [ ] الأمر `npm run dev` فتح المتصفح على `http://localhost:5173`، وظهرت أرض رملية وسماء فاتحة وأربعة أعمدة داكنة على مسافات مختلفة.
- [ ] العدّاد في الزاوية يعرض عدد الإطارات في الثانية وعدد أوامر الرسم والمثلثات.
- [ ] تغيير حجم النافذة لا يشوّه الصورة.
- [ ] أيقونة «OneShot Handoff» على سطح المكتب تنشئ ملف تسليم جديداً عند الضغط عليها.
- [ ] أول حفظ في غيت تم بنجاح.
- [ ] المستودع على غيت هب، وخط غيت هب أكشنز أخضر.
