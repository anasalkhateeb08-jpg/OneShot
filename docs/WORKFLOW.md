# طريقة العمل (من المالك)

## الأساس
- نعمل في بوورشيل على ويندوز ١١، والمشروع في `F:\OneShot`.
- الذكاء الاصطناعي يعطي الأوامر خطوة بخطوة، والمالك ينفّذها ويرسل النتيجة.
- الحديث بالعربية فقط. الحروف اللاتينية داخل الأوامر وأسماء الملفات والشيفرة فقط.
- كل ردّ يبدأ بـ «الحالة والقرار».
- مرحلة واحدة في كل مرة، ولا تبدأ مرحلة إلا بأمر المالك. إذا أراد المالك تعديلات أثناء العمل يخبر بها.

## تشغيل أمر وإرسال نتيجته
افتح بوورشيل بالطريقة العادية (ليس بصلاحيات المدير)، ثم:

```powershell
Set-Location F:\OneShot
.\tools\run.ps1 npm run check
```

الأداة تعرض الناتج وتنسخه كاملاً إلى الحافظة. ارجع إلى المحادثة واضغط كنترول + في.

## تسجيل التقدم
بعد كل خطوة مهمة يعطيك الذكاء الاصطناعي أمراً جاهزاً مثل:

```powershell
.\tools\update-status.ps1 -Status "..." -Decision "..." -Next "..."
```

هذا الأمر يحدّث `docs/STATUS.md`، ويضيف سطراً إلى `docs/PROGRESS.md`، ويحفظ نقطة رجوع في غيت.

## ملف التسليم لمحادثة جديدة
- أيقونة «OneShot Handoff» على سطح المكتب: اضغط عليها مرتين، ثم اضغط إدخال.
- يظهر على سطح المكتب ملف جديد اسمه `OneShot_HANDOFF_<التاريخ>.md` فيه كل شيء.
- أعطِ هذا الملف للمحادثة الجديدة لتكمل من حيث توقفنا.
- لإعادة إنشاء الأيقونة إن حُذفت: `.\tools\install-shortcut.ps1`
